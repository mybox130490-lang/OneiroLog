# Снотворец · OneiroLog

Юнгианский дневник-толкователь. Превращает заметки о дне в материал для анализа как
сновидение: даёт архетипическую трактовку, выявляет повторяющиеся паттерны внимания и
предлагает упражнения для смены фокуса сознания.

> Не гадание, а тренажёр внимания. Не предсказывает будущее, а показывает, **куда смотрит
> твоё сознание**, — чтобы ты мог этим управлять.

## Запуск

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Все данные хранятся **только в твоём браузере**
(localStorage). Ничего не уходит на сервер, пока ты сам не включишь живой ИИ.

## Что внутри

- **Сегодня** — запись дня: свободный поток / анкета-подсказка / голосовой ввод
  (🎙 Web Speech API, работает в Chrome). Мгновенная юнгианская трактовка с архетипами и
  уточняющими вопросами.
- **Паттерны** — ★ полупрозрачный **мыльный пузырь**, внутри которого плавают твои топ-образы
  и чувства. **Лопни его** — запустится кросс-дневная аналитика: топы, индекс направленности
  сознания, колеи и циклы (по дням недели), слепые зоны.
- **Упражнения** — задания по смене фокуса на основе паттернов + замер эффекта «до/после».
- **Лента** — все дни с трактовками.
- **Сон во сне** — месячная рекурсивная трактовка (этап жизни как единый сон) и режим
  **«Сон наяву»** (`/dream_now`): описать взгляд из окна → трактовка реальности как сна.
- **Словарь** — личный мифологический профиль: твои значения символов важнее общих.
- **Настройки** — ИИ-ключ, модель, слой-оракул (лунные циклы), бэкап, приватность.

## Трактовки: офлайн или живой Claude

По умолчанию работает **офлайн-движок** на встроенной базе архетипов и символов — бесплатно,
мгновенно, без интернета.

Для более глубоких трактовок в **Настройках** включи «Живой ИИ» и введи API-ключ Anthropic.
Модель по умолчанию — `claude-sonnet-4-6` (переключается на Opus 4.8 / Haiku 4.5).

> ⚠️ Ключ хранится в localStorage и шлётся напрямую из браузера. Это нормально для личного
> локального использования, но **не для публичного хостинга**.

## Слой безопасности

Перед любой трактовкой запись проходит проверку. Если в ней звучит острый кризис, приложение
**не** выдаёт «красивую» символику, а мягко возвращает к живой помощи (Телефон доверия
8-800-2000-122, экстренные 112). Это не диагностика — это страховочная сетка.

## Технологии

React 18 + Vite. Пузырь — Canvas 2D. Без бэкенда.

## Вне текущей версии (требуют сервера)

Анонимный коллективный слой (карта архетипов сообщества), интеграция носимых устройств,
вечерние голосовые звонки бота, полная астро-система Джойтиш.
